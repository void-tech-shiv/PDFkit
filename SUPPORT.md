# Getting Help

For usage questions and non-sensitive troubleshooting:

1. Read the [README](./README.md) and relevant guides in [docs](./docs/).
2. Search existing [GitHub issues](https://github.com/void-tech-shiv/PDFkit/issues) for a similar question.
3. If the problem is reproducible and not security-sensitive, open an issue with the environment, steps to reproduce, expected behavior, and actual behavior.

Use synthetic or redacted files when sharing examples. Do not upload private documents, passwords, API keys, or personal information.

For suspected security vulnerabilities, do not open a public issue. Follow [SECURITY.md](./SECURITY.md).

PDFkit is maintained by one primary maintainer. Support and issue responses are best-effort; no response-time guarantee is currently offered.
